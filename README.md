# TikToker — TikTok User Scraper

**TikToker** is a sleek, fully‑client‑side web application that extracts public TikTok profile data simply by entering a username. With a stunning forest‑green theme, AMOLED dark mode, an interactive world map, and import/export capabilities, it's the perfect tool for educational research and quick look‑ups.
